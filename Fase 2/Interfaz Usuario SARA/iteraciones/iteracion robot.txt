# Entorno de Desarrollo, Herramientas y Librerías: SARA (Etapa 1)

Este documento detalla el stack técnico, las dependencias de software y las especificaciones de hardware requeridas para la compilación, despliegue y enlace operativo del asistente robótico **SARA**.

---

## 1. Hardware del Chasis y Conectividad

* **Microcontrolador**: Arduino Uno (ATMega328P).
* **Controlador de Motores**: Módulo Puente H L298N.
* **Escudo de Expansión**: Sensor Shield V5.0.
* **Sensores de Proximidad**: Sensor ultrasónico HC-SR04 (Trigger: Pin 12, Echo: Pin 11).
* **Actuador Angular**: Micro Servomotor Tower Pro SG90 (Pin 3).
* **Alimentación Lógica**: Cable USB Tipo B macho a USB-C (enlace OTG) alimentado directamente por el smartphone.
* **Alimentación de Fuerza**: Pack de baterías externo para motores conectado a la bornera del L298N (con tierra común compartida hacia el Arduino).
* **Dispositivo Host ("Cabeza")**: Smartphone Android con soporte nativo de USB Host / OTG.

---

## 2. Entorno y Librerías del Firmware (Arduino)

### Software Requerido
* **IDE**: Arduino IDE v2.x o superior.
* **Placa**: Soporte oficial `Arduino AVR Boards` instalado desde el Board Manager.
* **Velocidad de Enlace Serie**: `115200 bps` (CU-19).

### Librerías del Sketch (`sara_control.ino`)
* `<Servo.h>`: Librería nativa de Arduino AVR para el posicionamiento del servomotor SG90 (Pin 3).
* Control de motores L298N: Implementado de manera directa mediante `digitalWrite` (eliminando interferencias de timers PWM con el servomotor en los pines 9 y 10).
* Muestreo del HC-SR04: Control de pulsos mediante `pulseIn()` sin dependencias externas para garantizar el frenado reactivo autónomo ($\le 15\text{ cm}$, CU-14).

---

### Especificaciones del Proyecto

## 4. Repositorios y Dependencias Gradle (`build.gradle.kts`)

### Configuración de Repositorios (`settings.gradle.kts`)
Es requisito indispensable agregar el repositorio JitPack para descargar el driver serie USB:

```kotlin
dependencyResolutionManagement {
    repositoriesMode.set(RepositoriesMode.FAIL_ON_PROJECT_REPOS)
    repositories {
        google()
        mavenCentral()
        maven("[https://jitpack.io](https://jitpack.io)") // Requerido para usb-serial-for-android
    }
}
```

## 5. Permisos de Manifiesto (`AndroidManifest.xml`)

Para permitir el acceso al hardware y la comunicación física con la placa:

```xml
<!-- Permiso de hardware para actuar como host USB con Arduino -->
<uses-feature android:name="android.hardware.usb.host" />

<!-- Permisos de captura y audio -->
<uses-permission android:name="android.permission.RECORD_AUDIO" />
<uses-permission android:name="android.permission.CAMERA" />

```

## 6. Protocolo de Comandos Serie (115200 bps)

| Comando | Acción en Arduino | Caso de Uso |
| --- | --- | --- |
| `1` | Avance al frente (rutina continua) | CU-18 |
| `2` | Giro 90° hacia la izquierda (`TIEMPO_GIRO = 260 ms`) | CU-18 |
| `3` | Giro 90° hacia la derecha (`TIEMPO_GIRO = 260 ms`) | CU-18 |
| `6` | Parada inmediata de motores | CU-18 |
| `EMERGENCY_STOP` | Mensaje emitido por Arduino ante obstáculo a $\le 15\text{ cm}$ | CU-14 |
