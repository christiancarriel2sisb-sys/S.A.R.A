# Movimiento Sara - Código de Control

Este directorio contiene el código fuente para el control de movimiento del proyecto SARA

## Archivos
* `prueba_sara.ino`: Código principal en Arduino para controlar los motores/servos.

## Requisitos y Componentes
* **Placa:** Arduino Uno.
* **Librerías:** `<Servo.h>`
* **Hardware:** Motores, driver controlador, fuentes de alimentación.

## Instrucciones
1. Abrir el archivo `prueba_sara.ino` en el IDE de Arduino.
2. Seleccionar la placa y el puerto COM correspondiente.
3. Cargar el programa a la placa.
