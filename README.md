# S.A.R.A - Asistente Robótico para Adultos Mayores

## Descripción del Proyecto
SARA (Sistema Asistente Robótico de Apoyo) es un proyecto de grado enfocado en brindar soporte, asistencia e interacción a adultos mayores, integrando módulos de interfaz de usuario y control de movimiento.
